# Клиент-серверное взаимодействие по TCP и UDP на WinSock2

Базовая реализация TCP и UDP клиент-серверного взаимодействия на C++ с использованием Windows Sockets 2 (WinSock2).

### Цель учебной задачи

Изучить основы сетевого программирования под Windows:
- понять разницу между TCP (надёжное соединение) и UDP (дата без соединения);
- освоить жизненный цикл сокета: `socket() → bind() → listen()` / `connect() → send/recv → closesocket()`;
- восстановление соединения при потере связи.

## Постановка задачи

Реализовать четыре программы, демонстрирующие базовые сценарии сетевого обмена:

| Файл | Роль | Протокол |
|:----:|:----:|:--------:|
| ServerTCP.cpp | Сервер | TCP |
| ClientTCP.cpp | Клиент | TCP |
| ServerUDP.cpp | Сервер | UDP |
| ClientUDP.cpp | Клиент | UDP |

TCP-пара: Сервер ожидает подключения, принимает клиента и ведёт пошаговый диалог: получает сообщение → выводит его → отправляет ответ. Клиент умеет переподключаться при потере связи.

UDP-пара: Сервер ожидает от любого клиента и отвечает фиксированной строкой. Клиент каждую секунду отправляет фиксированное сообщение и выводит ответ. Соединение не устанавливается.

## Схема работы

### TCP

```
[Сервер]                        [Клиент]
  bind()
  listen()
  accept() ◄────────────────── connect()
  recv()   ◄────────────────── send("сообщение")
  send()   ──────────────────► recv()
  ...            (диалог)       ...
  closesocket()               closesocket()
```

### UDP

```
[Сервер]                        [Клиент]
  bind()
  recvfrom() ◄──────────────── sendto("Привет, сервер!")
  sendto()   ──────────────────► recvfrom()
  (ждёт следующую датаграмму)   (sleep 1s, повторить)
```

## Сравнение TCP и UDP

| Аспект | TCP | UDP |
|--------|-----|-----|
| Установка соединения | Да (`connect`/`accept`) | Нет |
| Гарантия доставки | Да | Нет |
| Порядок пакетов | Гарантирован | Не гарантирован |
| Производительность | Ниже | Выше |
| Сложность кода | Выше | Ниже |
| Типичное применение | Чат, файлы, HTTP | VoIP, игры, DNS |
